# Evening review outputs (staging)

Artifacts from the **7 PM Daily Project Review** agent.

When the Cloud Agent cannot reach Bryan's MCP integrations (Google Calendar, Gmail, Stripe, session transcripts, Google Drive), files land here with `FAILED` status in `SAMANTHA_STATUS_evening-review_YYYY-MM-DD.json`.

Generated output files (JSON, HTML, MD) are gitignored to prevent sensitive operational data from being committed to this public repository. After a successful desktop run, copy artifacts to the configured cloud storage via MCP.
